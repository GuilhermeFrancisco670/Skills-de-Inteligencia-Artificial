Crie personagens de RPG consistentes em imagens geradas por IA para projetos de RPG de mesa (TRPG), RPG eletrônico (CRPG), MMORPG, LARP, RPG solo/livro-jogo e animação. O material inclui perguntas essenciais para o levantamento de dados, a estrutura completa de uma ficha de personagem de RPG (classe, raça, atributos, equipamentos, magias, facção, alinhamento), folhas de referência (vistas de diferentes ângulos, expressões, vestimentas, paletas de cores, miniaturas, sprites e figurinos), âncoras descritivas, técnicas de LoRA e *seed*, além de fluxos de trabalho específicos para cada gênero. A metodologia é independente da ferramenta: funciona com qualquer plataforma de geração de imagens (como Midjourney, Stable Diffusion, FLUX, DALL·E, ComfyUI, etc.). Gatilhos (*prompts*): *rpg character, character design sheet, character sheet, trpg character, dnd character, pathfinder character, crpg character, mmorpg character, larp costume, larp kit, gamebook illustration, solo rpg, rpg token, battle map token, vtt token, sprite sheet, character turnaround, expression sheet, rpg portrait, npc design, character bible, character consistency, oc design, rpg art, concept art*.
